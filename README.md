# Personal repo

This repo contains a hodgepodge of my personal projects. Some notable ones are
listed below.

## Dotfiles

My personal dotfiles. Mainly focussed on minimalism and tries to stick to
defaults where possible.

## Kobeni

A python discord.py bot. Functions as a bridge to my personal mumble server
instance. It keeps track of connected users and sends notifications on
updates.

## Lambda file server

A HTML page generator at its core running on AWS Lambda. Lists S3 buckets
contents, supports hidden files and folders, and intelligently caches
internally and using caching HTML headers for AWS Cloudfront.

## User scripts

A collection of useful scripts that go in ~/.local/bin or similar.
